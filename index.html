Personal Video Uploader

Personal Video Uploader is a private application designed to automate video uploads to the owner's YouTube channel.

Application Features

  • Automated YouTube video uploads
  • Secure Google OAuth 2.0 authorization
  • Video title and description management
  • Personal account integration

Google API Usage

This application uses the YouTube Data API to upload videos with the account owner's authorization.

The application is intended for personal use and is not offered as a public service.
